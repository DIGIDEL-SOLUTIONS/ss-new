# Rooflyzer Marketing Site

Static marketing website for [Rooflyzer](https://rooflyzer.pro) — AI-ready roofing OS (CRM + Smart Marketing + Estimator).

## Stack
- Static HTML / CSS / JS
- Gold brand accent `#f2cb6e`
- Interactive demos (roof scan, rehash timeline)

## Pages
- `/` — Homepage
- `/pages/features.html`
- `/pages/estimator.html`
- `/pages/smart-marketing.html`
- `/pages/compare.html`
- `/pages/pricing.html`
- `/pages/story.html`
- `/pages/demo.html`
- `/pages/sign-in.html`

## Local
Open `index.html` in a browser or serve with any static server.

```bash
npx serve .
```
